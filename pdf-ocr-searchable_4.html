Optical character recognition

Make a scan searchable

Reads the words off scanned pages and layers them invisibly back onto the page, so the PDF looks identical but you can select, copy and search the text. Also exports clean Markdown for feeding to an AI.

Processed locally. Recognition runs in this browser. The language model downloads on first use.
Drop scanned PDFs here or click to browse — multiple files welcome

How to read the page strip: each square is one page of the file.

read by OCR already had text, kept as-is couldn't be read, kept as an image not processed yet

Markdown export: alongside the searchable PDF you get a .md file with one section per page, headings, lists and tables recovered from the layout, and YAML front matter recording the source, page count and recognition confidence — the shape a language model reads best. Columns that aren't a solid grid are kept as aligned text rather than forced into a table, since a wrong header misleads more than plain lines do.

Worth knowing: the first run downloads the recognition model for your chosen language (a few MB), so it takes a moment before the first page starts. Pages are read at a fixed high resolution and get a deskew + contrast pass before recognition, so this favours accuracy over speed — budget several seconds per page. Long documents are built in batches to keep memory low, and you can stop a run at any time and keep what's been done so far. Accuracy still depends heavily on scan quality. Latin-alphabet languages only.
